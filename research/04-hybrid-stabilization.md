# 04. ハイブリッド予測と発散対策

設計メモ第2節（物理層＋リザバー層）・第3節（発散対策）の根拠。

## ハイブリッド予測（確立している話）

- Pathak, J., Wikner, A., Fussell, R., Chandra, S., Hunt, B. R., Girvan, M., & Ott, E. (2018). Hybrid Forecasting of Chaotic Processes: Using Machine Learning in Conjunction with a Knowledge-Based Model. *Chaos*, 28, 041101. https://arxiv.org/abs/1803.04779
  - 粗い（不完全な）物理モデルの出力とリザバーの出力を、学習した重みで線形結合する。
  - Lorenz系とKS方程式の両方で、**物理モデル単独・RC単独のどちらよりも予測可能時間が大きく伸びた**。
  - 物理モデルが大域の構造を担い、RCがモデルの誤差（クロージャ）を埋める、という役割分担は TAYUTAU の設計と一致する。

## 発散の原因（整理）

- 閉ループ予測では、自分の出力誤差が次の入力になる。状態が学習データの分布（アトラクタ上）から外れると、読み出しが外挿になり、誤差が増幅して暴走する。
- つまり問題は「カオスだから」ではなく「学習領域からの逸脱」。対策はすべて「逸脱を防ぐ／逸脱に強くする／逸脱したら戻す」に整理できる。

## 効きそうな手段（文献・実務の裏付けあり）

1. **拘束への射影（最も確実）**
   - 毎ステップ、予測状態を物理的拘束に射影する: 発散ゼロ化（圧力ポアソンではなく射影法として）、質量・エネルギー補正、値のクランプ。
   - TAYUTAUでは物理層が保存則を保証する設計なので、リザバー出力は「補正量」として加え、最後に物理層で射影するのが自然。
2. **訓練時ノイズ**
   - 教師入力に小さなノイズを加えて学習すると、閉ループで少しずれた状態からでも戻れる読み出しになる。Lu ら (2018) 系の実装で標準的に使われる。
3. **ナッジング（データ同化）**
   - 粗い物理ソルバーの状態へ、予測を弱く引き戻し続ける。ハイブリッドと組み合わせる研究もある（Wikner ら、ハイブリッド＋データ同化）。
   - ゲーム用途では「引き戻し先」が粗いソルバーになる。引き戻し係数は見た目の自然さで調整可能。
4. **逸脱の監視と再初期化**
   - 状態のノルムや物理量（全質量・全エネルギー）が学習範囲を外れたら検知し、物理ソルバーの状態でリザバーを再ウォームアップする。

## 第2リザバー（補正器）について — 独自案・未検証

- 設計メモの案: 小さな第2リザバーに「ずれた状態 → 正しい状態への補正量」を学習させる。
- これはカオス制御（OGY法・遅延フィードバック制御）とは別物で、学習型フィードバック補正と呼ぶべきもの。OGY等の古典的カオス制御は「目標軌道の近傍での線形安定化」が前提で、分布逸脱の回復には直接使えない。
- 近い考え方（誤差モデルを別に学習して補正する）は機械学習一般にはあるが、リザバー補正器としての実証論文は 2026-11-24 時点で未確認。**実験で確かめる項目**として扱う:
  - 実験案: Lorenz系で、意図的にずらした状態から補正器あり／なしで回復率（アトラクタへ戻れる割合と時間）を比較する。

## まとめ（実装順序）

1. まず射影＋訓練時ノイズで土台を作る。
2. ハイブリッド結合（物理モデル出力とRC出力の重み付き和）で予測時間を伸ばす。
3. それでも崩れる場合にナッジングを足す。
4. 補正器は最後の実験枠。
