# research/ — リザバー実装のための調査ノート

## 目的

リザバーコンピューティング（ESN / NVAR / 並列リザバー / ハイブリッド型）を、
**最新まで確実に、効率よくコーディングする**ための調査置き場。

- 実装時にAI（Claude Code など）へ渡すコンテキストとして使う。
- 主張には出典（論文タイトル・著者・年・リンク）を付ける。
- 「確立している話」「1本の論文だけの主張」「推測・独自案」を区別して書く。
- 設計判断そのものは `docs/design-memo.md` 側に置く。ここは根拠と実装詳細。

## 書き方の約束

- 数式は LaTeX 記法で書き、変数の shape を必ず添える。
- 論文に書かれていない設定値は「論文に記載なし」と明示する。推測で埋めない。
- 再現の基準は Lorenz 系（予測可能時間をリアプノフ時間の倍数で測る）。
